# pulsar-classification

Classifying pulsar stars using 3 different classification techniques:
- Logistic Regression
- Random Forest
- Gradient Boosting

Dataset I used:
https://archive.ics.uci.edu/dataset/372/htru2

The dataset are pulsar candidates. The task is to classify whether or not a candidate is a pulsar or not. Then, we can find the accuracy based on the last column, which is the class.
